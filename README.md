
# Student Grade Management System

## About the Project
A beginner-friendly Java application that helps calculate student grades and generate a formatted result card.

## Features
- Enter college and student details.
- Choose the number of subjects.
- Dynamically generate subject name and marks fields.
- Automatically calculate total marks and average.
- Generate grades based on performance.
- Display a formatted result card in a popup window.

## Technologies Used
- Java
- Java Swing
- AWT

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program:

   javac Main.java

4. Run the program:

   java studentgrade.Main
